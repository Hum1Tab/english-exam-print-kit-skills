# A4印刷・ミニブックの制作仕様

## 出力とプリンタ設定

- 解答・解説：A4縦、用紙余白12〜14mm、簡素な見出し。長い表には適切な列幅を設ける。
- 単語・熟語：A4縦、1〜2段組。英単語と読み・意味が別ページに分かれないようにする。
- ミニブック：A5・8ページ（ページ2に英文全文、ページ3に和訳全文）。段落単位で区切る。
- 印刷用面付け：A4横4面、ページ番号の組み合わせは `8|1` → `2|7` → `6|3` → `4|5`。
- 一括印刷：A4縦に統一、両面・長辺とじ。最後の4面はA4横の面付けを交互に90度・270度回転して載せる。解答＋単語部分が奇数枚の場合は空白1ページで前後を揃える。

## 注意すること

1. すべてのPDFのページサイズを検査。A4縦以外が混ざるなら一括印刷時に修正。
2. 全ページをPNGにレンダリングし、接頭のページ・語彙表・最後の2ページで必ず目視する。
3. 改ページ直後に「前の表の最終1行だけ」が現れないようにする。
4. 英文の語間が詰まりすぎないように行間を確保。日本語9ptでも狭い字間を避ける。
5. 両面の「長辺とじ」の意味は向きに依存。A4横の折り用面付けを単純に縦置きすると裏面が逆になるので、面ごとの回転を明示的に区別する。
6. ミニブックが8ページでないなら、次の4の倍数まで空白を追加することをユーザーに断ってから一般化する。この実装は8ページを標準とする。
7. 試し刷りを最優先する場合、A4両面の後に中央で折り、見開きが連番になるか確認する。

## 出典表示

ユーザーから不要と言われているため、ページ脚注・タイトル下・本文末尾に出典やURLを入れない。ただし作業内部では、設問と解答に使った元PDFの名前・ページを残す。
