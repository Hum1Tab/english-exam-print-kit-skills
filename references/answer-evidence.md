# 内容一致：根拠文から判断する Skill
対象の選択肢をすべて「判定／本文の段落・文番号／言い換えまたはズレ／誤りの型」で説明する。正答だけを先に丸暗記させない。
## 手順
1. 本文は段落の機能（導入・調査・理由・例・譲歩・結論）を1行ずつ把握する。
2. 選択肢で主語・対象・数値・場所・期間・原因・否定・強弱をチェックする。
3. 対応する本文位置まで戻って照合する。本文にないことは『書いていない』とする。
4. 誤りの型を分類：対象のすり替え／範囲の拡大／因果の逆転／原因の捏造／勧奨と禁止の混同／否定の見落とし／本文にない憶測。
5. 設問が複数選択でも全部の選択肢を判定し、指定個数を当てるだけで終わらせない。
6. 復習時は『本文が読めなかった』と『本文は読めたが選択肢の論理を誤った』を分離する。
